# RoleVerse Bot

Telegram bot для RoleVerse - мистический ролевой опыт в готическом мире Района Пепла.

## Установка

```bash
npm install
```

## Настройка

Создай `.env` файл:

```
BOT_TOKEN=your_telegram_bot_token
HF_API_KEY=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
```

## Запуск

```bash
npm start
```

## Деплой на Railway/Render/Fly.io

1. Создай репозиторий GitHub
2. Загрузи код
3. Подключи к Railway/Render
4. Добавь переменные окружения:
   - `BOT_TOKEN`
   - `HF_API_KEY`
